# Security

## Your API keys

- Keys are typed into your own browser and sent **only** to the AI service you choose.
- With **Remember on this computer** ticked, the key is stored in that browser's `localStorage`. Don't tick it on shared or lab computers.
- No key is ever stored in this repository. If you think a key leaked, delete it in that service's dashboard right away and create a new one.

## Reporting a problem

If you find a security issue, like a way for a web page to read someone's key, please **don't open a public issue**. Contact the maintainer through their GitHub profile instead: [@frediljosue](https://github.com/frediljosue).
